# Ansible Completion Checklist

- [ ] Supported Ansible/Python versions identified
- [ ] Inventory target and variable precedence understood
- [ ] Modules preferred over shell commands
- [ ] Commands have idempotency guards
- [ ] Handlers used for reload/restart
- [ ] Secrets are not committed or logged
- [ ] Syntax check performed
- [ ] ansible-lint/yamllint performed when available
- [ ] Check mode and limited execution considered
- [ ] Role variables and examples documented
- [ ] Rollback or recovery documented
- [ ] Repository artifacts are in English
