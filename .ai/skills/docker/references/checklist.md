# Docker Completion Checklist

- [ ] Build context and ignore file reviewed
- [ ] Image tag/version policy followed
- [ ] Non-root execution considered
- [ ] Secrets excluded from image and repository
- [ ] Compose configuration validates
- [ ] Persistent data paths identified
- [ ] Health checks are meaningful
- [ ] Public ports minimized
- [ ] Privileged mode/socket mounts/capabilities reviewed
- [ ] Logging and resource behavior considered
- [ ] Data migration and rollback documented
- [ ] Repository artifacts are in English
