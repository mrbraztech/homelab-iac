# Infrastructure Task Report

## Objective

Describe the requested outcome.

## Current state

Summarize observed repository and environment facts. Separate assumptions explicitly.

## Proposed or implemented changes

List the exact files, resources, commands, or configuration changed.

## Validation

Record commands run and their observed results. Do not claim checks that were not executed.

## Impact and risks

Document downtime, replacement, data loss, security, cost, compatibility, and operational risks.

## Rollback

Provide a concrete rollback or recovery procedure.

## Remaining actions

List approvals, environment-only validation, secrets, or deployment steps still required.
