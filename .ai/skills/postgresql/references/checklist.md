# PostgreSQL Completion Checklist

- [ ] Server version and target database identified
- [ ] Backup status confirmed before risky changes
- [ ] Lock and downtime implications analyzed
- [ ] Least-privilege roles and ownership used
- [ ] Secrets excluded from scripts and logs
- [ ] Migration compatibility and rollback considered
- [ ] Query plans measured safely
- [ ] Index write overhead considered
- [ ] Backup includes restore validation
- [ ] Major-version upgrades use an explicit migration procedure
- [ ] Validation queries included
- [ ] Repository artifacts are in English
