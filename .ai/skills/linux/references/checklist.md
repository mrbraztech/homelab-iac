# Linux Completion Checklist

- [ ] OS/version and runtime environment identified
- [ ] Evidence collected before mutation
- [ ] Existing configuration backed up where needed
- [ ] One controlled change applied at a time
- [ ] Remote access preserved
- [ ] Permissions follow least privilege
- [ ] Firewall changes are narrow and reversible
- [ ] Mount/device identity verified safely
- [ ] Service status and logs validated
- [ ] Persistence across restart/reload checked
- [ ] Rollback documented
- [ ] Repository artifacts are in English
